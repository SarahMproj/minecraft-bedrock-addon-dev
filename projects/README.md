# Minecraft DLC Projects

This directory contains product-specific development work built with the `minecraft-bedrock-addon-dev` skill and tooling.

## Operating rule

Every DLC project maintains a persistent `STATUS.md` that is updated at the end of every work session across the same categories:

- Bedrock engineering capability
- DLC portfolio/product strategy
- Content design
- Brand / visual universe
- Competitive research
- Behavior Pack / Resource Pack implementation
- Models / textures / icons
- Playable package
- Device / multiplayer testing
- Publisher / Marketplace track
- Creator GTM / gameplay capture
- Current milestone
- Blockers / risks
- Next session

The status file should distinguish clearly between **designed**, **implemented**, **validated**, **play-tested**, and **shippable**.
